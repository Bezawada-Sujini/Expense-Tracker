# Expense Tracker
A simple command-line expense tracker built in Python

## Features
- Add expenses with amount, category, and note
- View all expenses
- See total spending
- Filter expenses by category
- Delete an expense (with undo/restore option)
- Data is saved automatically to a JSON file, so it persists between runs

## How to run
1. Make sure Python 3 is installed
2. Run: `python expense_tracker.py`
3. Follow the on-screen menu

## What I learned
- Working with Python data structures (lists, dictionaries)
- File handling and JSON for data persistence
- Writing clean, modular functions
- Basic error handling for invalid input
